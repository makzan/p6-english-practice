# P6 English Practice 小六英文練習

Small, self-contained interactive English practice pages for primary 6 (pure HTML/CSS/JS, no libraries, works offline).

- `index.html` – home page listing all practices as cards
- `unit2-vocabulary/` – Unit 2 vocabulary spelling practice (Chinese prompt + English speech via Web Speech API; wrong answers are repeated at the end)

To add a new practice: create a new folder with an `index.html`, then copy a card block in the root `index.html` and point it to the new folder.

Hosted with GitHub Pages.
